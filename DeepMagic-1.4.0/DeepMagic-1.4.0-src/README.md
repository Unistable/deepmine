# DeepMagic 1.4.0 MENU — исходный код

Магический аддон для сервера **Paper 1.21.11** поверх системы прогресса
**DeepProgression 3.2.1**. Полностью самостоятельный плагин
(`depend: [DeepProgression]`, `softdepend: [DeepSpawn]`), ничего из
DeepProgression не изменяет.

## Что внутри

- **Меню-арсенал `/mage`** — GUI в стиле DeepProgression (Gui v3):
  сетка секций → ветки → посох с лестницей тиров → рецепт 3×3
  (компонент + вещество + медаль), гайд «Путь мага», матрица синергий,
  каталог всех 73 посохов (фильтр секций + пагинация), профиль мага
  (гейты, посохи в инвентаре). Информационные команды чата удалены:
  `/mage handbook`, `/mage list`, `/mage help` больше не существуют.
- **Магический компрессор** — машина с GUI v2 (54 слота, живой прогресс,
  зоны вход/выход, топливо, режимы сжатия по редкостям). Превращает
  ресурсы из реестра DeepProgression в «сверхсжатые вещества»
  (64 000 моркови → Сублимированный Морковный Композит и т.д.).
- **73 вещества** — уникальные названия, лор, редкость (tier) у каждого.
- **73 посоха** — по веществу на каждый, у каждого своя механика,
  привязанная к природе ресурса (уголь: коксовое покрытие + вечное пламя
  до воды + угольная пыль/удушье; и т.д. — ни одной копипасты «просто урон»).
- **Матрица синергий** — законы взаимодействий элемент × элемент × среда
  (уголь + огонь = вечное пламя; вода гасит; и т.д.).
- **Гейты прогресса** — посохи и вещества привязаны к медалям/тирам
  DeepProgression: магия растёт из прогресса, а не обходится его.
- **Компрессор — экономическая раковина**: жрёт ресурсы, топливо и время.

## Сборка

### Требования

- **JDK 21+** (нужны `javac` и `jar` именно из JDK).
- **paper-api-1.21.11** — на работающем сервере лежит в
  `libraries/io/papermc/paper/paper-api/1.21.11-R0.1-SNAPSHOT/`; отдельно
  скачивается с papermc.io (артефакт
  `io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT`).
- **DeepProgression-3.2.0.jar** — из `plugins/` сервера.
- Если `javac` пожалуется на отсутствующие типы (adventure, gson, guava…)
  — положите эти jar туда же в `libs/` (все они есть в `libraries/`
  сервера).

### Как собрать

```bash
mkdir libs
# скопируйте в libs/:
#   paper-api-1.21.11-R0.1-SNAPSHOT.jar
#   DeepProgression-3.2.0.jar
#   (+ adventure-*.jar, gson, guava и т.п., если компилятор попросит)

./build.sh
# → DeepMagic-1.4.0.jar
```

Готовый jar кладётся в `plugins/` сервера рядом с
`DeepProgression-3.2.0.jar`. Первый запуск создаёт
`plugins/DeepMagic/config.yml`.

## Проверка после установки

- `/mage selftest` — встроенный аудит: реестр, рецепты, гейты, гигиена
  имён (ни одного сырого `&`), GUI-инварианты. Должен ответить
  «ВСЁ ЗЕЛЁНОЕ, 0 ОШИБОК».
- `/dmtest compressor|burn|burnwet|gui|clean` — функциональные тесты
  (право `deepmagic.admin`, по умолчанию — оператор).
- `/mage` — меню-арсенал: крафты всех посохов, каталог, синергии, профиль.
- `/mage selftest` — должен ответить «812 OK, 0 FAIL».
