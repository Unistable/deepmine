# CHANGELOG

## 1.4.0 — MENU (2026-11-10)
Меню-арсенал вместо команд. Информационные команды чата удалены.

### Новое
- **`/mage` — «Магический Арсенал»** (пакет `ru.deepmagic.menu`): GUI в стиле
  DeepProgression (Gui v3): сетка секций, ветки, витрина посоха, лестница тиров,
  рецепты 3×3 (компонент+вещество+медаль) с навигацией, гайд «Путь мага»,
  матрица синергий, каталог 73 посохов (фильтр секций + пагинация),
  профиль мага (гейты, посохи в инвентаре). Звуки, градиентные заголовки,
  статус гейтов из профиля DP.
- УДАЛЕНЫ: `/mage handbook`, `/mage list`, `/mage help` — всё внутри меню.
  Остались админские: `/mage give|selftest|reload` (+ `/mage menu`).
- Selftest дополнен инвариантами меню (иконки, витрины, рецепты, каталог).
- Святилище спавна: мост `SpawnGuard` (softdepend DeepSpawn) — посохи
  глушатся в спавн-зоне DeepSpawn.
- Витринные предметы меню стерильны (`ItemDefs.clearIds`) — PDC нет,
  механики их не видят.

### Изменённые файлы
- НОВЫЕ: menu/MenuGui.java, util/SpawnGuard.java
- MageCmd.java — минус handbook/list/help, плюс меню и selftest-пункт
- MagicListener.java — маршрутизация кликов/драга меню
- ItemDefs.java — clearIds()
- StaffUse.java — глушение в спавн-зоне
- plugin.yml — 1.4.0, softdepend DeepSpawn

### Гарантии
- Крафты/механики/гейты не изменены (gameplay 1.3.0 нетронут).
- Меню не выдаёт предметов: витрины без PDC, клики гасятся.

## 1.2.0 — SPECTACLE (2026-11-10)
Зрелищный редизайн: ВСЕ 73 посоха получили эпичные уникальные визуалы.

### Движок (новый пакет ru.deepmagic.fx)
- **Spectacle** — FX-движок: физичные BlockDisplay/ItemDisplay-орбиты (без коллизии,
  setPersistent(false), PDC-тег, кап 480 дисплеев / 140 работ — TPS защищён),
  тикер каждые 2 тика, плавные fade через интерполяцию, переап при старте/стопе.
- **SpellFx** — персональная сцена каждого посоха.
- Автосостояния: 16 состояний имеют визуал (орбиты/вспышки) при наложении
  и дешёвые секундные акценты; орбиты привязаны к PDC-состоянию и тают при смыве.
- Зоны (мох/мёд/ритуал/обелиск) размечаются мягкими кольцами частиц.
- Вечное горение и угольная пыль получили живые акценты.

### Пример ТЗ выполнен (Угольный посох)
Цель покрывается углём: вокруг неё летают **физичные угольные блоки без коллизии**,
вспыхивает **эффект тотема с углём вместо тотема**; при смыве водой блоки плавно тают.

### Изменённые файлы
- НОВЫЕ: fx/Spectacle.java, fx/SpellFx.java
- Mechanics.java — FX-вызовы во всех 73 case (gameplay-логика не тронута)
- State.java — визуал при наложении состояния + секундные акценты
- EternalBurn.java, Synergy.java — акценты огня/пыли, разметка зон, акцент матрицы
- DeepMagicPlugin.java — init/shutdown движка
- DmTestCmd.java — новый тест `/dmtest fx` (+чистка FX в clean)
- plugin.yml — 1.2.0

### Гарантии
- Gameplay не изменился: урон, состояния, кулдауны, топливо — как в 1.1.0.
- FX не влияет на серверную логику: при переполнении капа эффект пропускается.
- Все дисплеи не персистентны — «призраков» после рестарта не бывает.
