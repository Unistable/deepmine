## 3. Глобальная экономика (economy/Economy.java)
- Счётчики добычи по материалам-ресурсам (total + week), async-файл economy.yml, неделя ISO.
- Индекс = clamp(1..10, round(V / (1 + log10(1 + total/5000)))) где V — собственная
  ценность материала (конфиг economy.values, дефолт по группе).
- V по группам: незерит 10, алмаз/изумруд/древние обломки/эхо-осколок 9, золото/аметист 7,
  медь/железо/кварц/лазурит/редстоун 5, уголь 4, дерево/камень/сельхоз/песок 1–3 и т.д.
- Хук: добыча (Drills.*, ChunkDrill) → Economy.mined(material, units).
- Хук: награда контрактов ×(1 + (index−5)·0.08), min ×0.6 (спрос двигает награды).
- GUI /dp economy: страницы, сортировка по индексу ↓, lore: индекс, V, всего, за неделю.
- Команда: /dp economy [стр]. Лидер экономик: самый дефицитный материал (индекс 10) в чате раз в час? нет — только по запросу.

## 5. Эхо-камера (машина аномалий, CALIBRATED_SCULK_SENSOR)
- SCULK ×24 → ECHO_SHARD ×1 (+15% аметист ×2)
- SCULK_CATALYST ×1 → ECHO_SHARD ×2 (+25% DISC_FRAGMENT_5 ×1)
- CALIBRATED_SCULK_SENSOR как блок машины нельзя (не TileState) → иконка CALIBRATED_SCULK_SENSOR,
  блок машины = SCULK_CATALYST? Нет: машины ставятся только из TileState блоков (place() проверяет).
  Блок: SCULK_SHRIEKER не TileState… Использовать Material.CALIBRATED_SCULK_SENSOR нельзя;
  берём Material.JUKEBOX (TileState, «коробка эха») с иконкой ECHO_SHARD? Иконка предмета =
  ECHO_SHARD, ставится как JUKEBOX. Звук: BLOCK_SCULK_SENSOR_CLICKING, частицы SOUL.
