## 2. Механизм крафтов — двойной, надёжный без клиента

1. **Vanilla ShapedRecipe** — рецепты только из ванильных материалов
   (steel_ingot, steel_plate, copper_wire, redstone_coil, coal_electrode,
   iron_gear, quartz_chip, obsidian_casing, drill_rod, geologist_pick).
2. **Ручной matcher** (все остальные, с кастомными ингредиентами и медалями):
   - PrepareItemCraftEvent → Recipes.matchMatrix(trimmed сетка vs spec) → setResult;
   - InventoryClickEvent (слот результата верстака) → строгий re-match →
     cancel → вычесть по 1 из каждого занятого слота → выдать (shift — цикл).
   - Ингредиент: Material (чисто ванильный: тегированные предметы НЕ матчатся) |
     toolId (PDC TOOL_ID) | медаль (PDC MEDAL=BRANCH:tier, tier ≥ требуемого).
   - v1-подзарядка зонда (probe+battery) — сохраняется (matchMatrix её не матчит).

## 3. Хранилища руд

- **Рудный тайник** (портативный): PDC-строка "MATERIAL:count,..." (лимит
  config, 4096 ед.), фильтр — стандартные дропы руд + GOLD_NUGGET.
  - авто-маршрут: Drills.give → тайник до инвентаря; EntityPickupItemEvent →
    рудные предметы в тайник (остаток — обычный подбор);
  - ПКМ — GUI 27 (MenuType.POUCH, фильтр кладки не-руды);
  - Shift+ПКМ — ссыпка всей руды из инвентаря в тайник.
- **Рудный склад** (блок BARREL): ванильный инвентарь 27; Shift+ПКМ с рудой —
  ссыпка; хопперы: фильтр InventoryMoveItemEvent (только руды внутрь);
  ломание → содержимое дропается, кастом-предмет возвращается.

## 4. Машины (TileState + PDC MACHINE)

- **Зарядная станция** (FURNACE): ПКМ → платформа 3×3 магмы под блоком
  (≥5 блоков, config): зонд в руке → +3 заряда; чанковый бур → полный заряд
  (состояние CHARGED без расхода магмы). Кулдаун станции 60с (PDC).
- **Геосканер** (SMOKER): ПКМ → бесплатный скан чанка (модуль Probe),
  кулдаун 30с на блок (PDC).
- Установка: BlockPlaceEvent — исключение из запрета, кастомное имя
  (Nameable.setCustomName) + PDC-тег. Ломание: содержимое → дроп, кастом-предмет →
  игроку. Защита: взрывы (EntityExplode/BlockExplode), поршни.

## 5. Новые системы

- **Ежедневные контракты**: 3 из пула 12 (seed = день+uuid), типы MINE(ветка,N)
  и CRAFT(id,N), прогресс в профиле, авто-награда компонентами; /dm quests.
- **Жилы удачи**: при добыче руды шанс (config 0.3%) → бонус = базовый дроп ×
  lucky_mult (25), экшен-бар+звук+частицы; редкие ветки → анонс серверу.
- **Перки званий**: тир ≥ 4: шанс двойного дропа своей руды
  (per_tier=2%, cap 10%).
- **/dm top [ветка]** — топ-10 по конкретной ветке (без ветки — по очкам, v1).

## 6. Совместимость

- v1-предметы (PDC) работают; старые простые крафты бУРОВ удалены (заменены
  глубокими); v1-медали совместимы с новыми крафтами.
- Профили: добавляются поля quests (обратимо — старые файлы читаются).
- GUI: каталог крафтов = «корневые» предметы (22), компоненты открываются
  кликом по ингредиенту в RecipeMenu (навигация по дереву вверх).
- Команды: +quests, top [branch]; give поддерживает все новые предметы
  (единый Tools-реестр).
