# DESIGN.md — DeepMining v1.0.0 (рабочий дизайн-документ)

Плагин Paper 1.21.11, пакет `ru.deepmining`, без внешних зависимостей.
Интерфейс: русский. Хранение: YAML. Разработчик-исполнитель: агент по AGENTS.md.

## 1. Концепция

Узкоспециализированная добыча: 11 веток материалов, в каждой — 10 званий
(медали выдаются предметами в инвентарь при достижении порога) и свой бур.
Универсальные инструменты перекрывают все ветки слабее. Инфраструктура:
зонд георазведки (скан чанка), чанковый бур (выгребает руды целого чанка,
заряд магмой), геологическая батарея (заряд зонда), кирка геолога (входная).

## 4. Стандартные дропы руд (поскольку getDrops не учитывает удачу)

coal→COAL×1; copper→RAW_COPPER×3 (середина 2–5); iron→RAW_IRON×1; gold→RAW_GOLD×1;
nether_gold→GOLD_NUGGET×4; redstone→REDSTONE×4; lapis→LAPIS_LAZULI×6;
diamond→DIAMOND×1; emerald→EMERALD×1; quartz→QUARTZ×1; debris→ANCIENT_DEBRIS×1.
Каменное семейство: stone→cobblestone, deepslate→cobbled_deepslate, остальное→само.

Все буры: Efficiency VI (скрыто), авто-подбор дропа в инвентарь (остаток — на землю).

## 6. Чанковый бур — конечный автомат

EMPTY →(ПКМ: списать 128 магмы из инвентаря)→ CHARGED →(ПКМ: кулдаун 30с, запуск
выработки: посекционно за 24 тика, каждая руда → замещается базовым камнем
(deepslate<0 / netherrack в незере), с вероятностью 90% попадает в хранилище
в стандартном эквиваленте §4)→ LOADED →(Shift+ПКМ: выгрузка в инвентарь,
остаток остаётся в буре)→ EMPTY. Содержимое — PDC-строка "MATERIAL:кол-во,...",
лимит 20000 единиц. Прогрессия ×0.5 за каждую руду. Эффекты: частицы FLAME/LAVA,
звук поршня посекционно. CoreProtect логирует изменения штатно.

## 7. Зонд георазведки

ПКМ → асинхронный скан снимка чанка (getBlockType по Y мира) → отчёт в чат:
кол-во каждой руды в чанке (desc), индекс богатства (вес: coal1, copper2, iron3,
gold5, redstone4, lapis4, quartz3, diamond10, emerald8, debris25), подсказки Y-уровней.
Расход 1 заряд; кулдаун 3с; 0 зарядов → подсказка про батарею. Батарея: крафт
зонд+до 4 батарей → +2 заряда каждая; или ПКМ батареей с зондом в оффхенде.

## 8. Крафты (ShapedRecipe, ключ deepmining:<id>)

- geologist_pick: булыжник/железо/булыжник · железо/алмаз/железо · палки×3
- drill_coal: угоблок×3 / редблок·алмаз·редблок / желблок×3 (и аналогично по веткам:
  B=блок ветки, R=редстоун_блок, D=алмаз, I=железо_блок; исключения:
  drill_stone: булыжник×3 / редблок·желблок·редблок / жел-ингот×3;
  drill_iron: желблок×3 / редблок·алмаз·редблок / угоблок×3;
  drill_redstone: редблок×3 / золблок·алмаз·золблок / желблок×3;
  drill_diamond: алмблок×3 / редблок·изумруд·редблок / желблок×3;
  drill_debris: обломки×3 / алмблок·незерит_слиток·алмблок / незерит_слитки×3)
- universal_1: угоблок/медблок/желблок · золблок/алмаз/редблок · лазблок/измблок/кварцблок
- universal_2: обсидиан×3 / редблок·незерит_слиток·редблок / алмблок×3
- universal_3: незблок×3 / обсидиан·незер_звезда·обсидиан / алмблок×3

Подзарядка зонда — PrepareItemCraftEvent (зонд + батареи), результат строится кодом.

## 9. Команды (/dm, /deepmining)

menu (GUI), progress [ветка] (GUI/чат), crafts [инструмент] (GUI каталога/рецепта),
stats, top (топ-10 по очкам, async), medals [ветка] (пере-выдача), give <игрок>
<id> [кол-во] (admin), reload (admin), help. Права: deepmining.use (default true),
deepmining.admin (default op).

## 10. GUI

MainMenu 27: 11 веток + универсальные + крафты + статистика + закрыть.
BranchMenu 54: иконка ветки со статистикой, 10 званий (готово/текущее/закрыто,
прогресс-бар), назад. CraftsMenu 54: каталог инструментов. RecipeMenu 36:
сетка 3×3 ингредиентов, стрелка, результат. Клик в GUI — отменяется; кнопки работают.

## 11. Хранение и производительность

players/<uuid>.yml: blocks.<BRANCH>, medals.<BRANCH>.<tier>=дата.
Загрузка: AsyncPlayerPreLoginEvent; сохранение: onQuit (async) + период 5 мин +
изменение тира (async). Кэш в памяти EnumMap. Скан зонда — off-main по снимку.
Выработка чанкбура — 1 секция (16³=4096 блоков) за тик. EnumSet/EnumMap в
горячем пути, без лишних аллокаций.

## 12. Совместимость

WorldGuard: слушатель HIGHEST + ignoreCancelled. CoreProtect: пишется штатно.
Multiverse: миры фильтруются (worlds: [] = все). Оффлайн-сервер: не влияет.
Не использовать enum Sound (строковые playSound), Particle — только стабильные
константы (FLAME/LAVA/CLOUD/CRIT), чаты через legacy §. ItemMeta legacy-методы
(deprecated, присутствуют в 1.21.11 API).
