# DeepEvents 1.0.0

Кинематографичные случайные ивенты для Paper 1.21.11 (работает на Paper 1.21.x, Java 21+).
Три ивента: **Кракен Бездны** (босс-осада), **Ядерный взрыв** (катастрофа с кратером) и
**Звездопад** (мирная ночь желаний).

Автор стиля экосистемы DeepProgression. Без NMS, только Paper API + Display Entities.

---

## Установка

1. Положите `DeepEvents-1.0.0.jar` в папку `plugins/` сервера.
2. Перезапустите сервер — появится `plugins/DeepEvents/config.yml`.
3. (Рекомендуется) WorldGuard: если установлен — ивенты не трогают защищённые регионы
   (точка ищется с проверкой, а кратер дополнительно проверяет весь периметр и
   откатывается, если задел регион).

Совместимость: softdepend WorldGuard/Towny/CoreProtect. Towny не хукается напрямую —
защита построек обеспечивается дистанцией до игроков/спавна (120/200 блоков по умолчанию)
и командой `/deepevents undo`. CoreProtect дополнительно залогирует все изменения блоков.

> Важно: если на сервере плагины, собранные под Java 25 (как WorldGuard/WorldEdit
> из поставки DeepProgression 3.2.1), запускайте сервер на Java 25 (в комплекте jre25).

## Команды `/deepevents` (алиасы `/events`, `/devents`)

| Команда | Право | Описание |
|---|---|---|
| `/deepevents status` | все | Активный ивент, таймер следующего, число радиационных зон |
| `/deepevents trigger <kraken\|nuke\|starfall\|random>` | admin | Запустить ивент вручную |
| `/deepevents stop` | admin | Остановить текущий ивент (кратер остаётся, см. undo) |
| `/deepevents undo` | admin | Откатить последний кратер (включая после рестарта) + снять радиацию |
| `/deepevents selftest` | admin | 10 внутренних проверок (конфиг, лут-математика, волны, кратер) |
| `/deepevents reload` | admin | Перечитать конфиг и перепланировать ивенты |

Автопланировщик: случайный ивент раз в 45–90 минут (настраивается), предупреждение за
60 секунд, не повторяет один и тот же ивент дважды подряд, требуется игрок онлайн.

## Ивент 1: Кракен Бездны

В глубоком океане просыпается гигантский босс. Это не «приди и закликай» — это осада:

1. **Щит Бездны.** Кракен неуязвим, пока на 3 алтарях вокруг арены живы **Аколиты Бездны**
   (утопленные с трезубцами, светятся). Убейте всех трёх → ядро открывается на 25 секунд.
2. **Ядро открыто** — единственное окно, когда урон засчитывается. Потом щит вернётся,
   аколиты возродятся, а Кракен будет медленно регенерировать под щитом.
3. Параллельно мешают:
   - **Щупальца** — анимированные колонны из BlockDisplay, целит в игрока
     (сужающееся красное кольцо = честный телеграф) и бьёт слэмом;
   - **Цунами-волны** — физичные блоки воды **без коллизии**, фронт движется по формуле
     бегущей волны `η(x,t) = A·sin(2πx/λ + φ)`, гребень с пеной. **Нырните под волну —
     и она вас не заденет** (это контрплей);
   - **Водовороты** (фаза 2) — затягивают и крутят;
   - **Отродья Бездны** (стражи) — отвлекают;
   - **Фаза 3** — волны и слэмы чаще.
4. **Лут делится поровну** между всеми, кто нанёс урон (round-robin по всему пулу,
   включая трезубец и книги). Трофей «Сердце Кракена» уходит случайному охотнику.

Киношный вход: океан вспухает, от арены расходятся волны, босс поднимается из бездны
под молнию. Боссбар виден только вблизи арены (80 блоков) — чат сервера не спамится.

Если босса никто не атакует 5 минут — он уходит в бездну. Максимум ивента — 15 минут.

## Ивент 2: Ядерный взрыв

Последовательность «как в кино»:

1. **Сирена** 10 секунд: титул с координатами вспышки, тревожный вой.
2. **Детонация**: вспышка, взрыв, **ударная волна** — расширяющееся кольцо (70 блоков):
   урон с линейным спадом от 12 в эпицентре, отбрасывание от центра, мобы в эпицентре гибнут.
3. **Грибовидное облако** — ствол, раскрывающаяся шляпа, приземный пылевой вал.
4. **Кратер** (R=27, глубина 13, ~20 000 изменённых блоков): параболоид с шумовым контуром,
   **тринитит** (стекло) в центре, кольца магмы/базальта/булыжника, вал на кромке,
   выжженная земля, **обугленный лес** (листва выгорает, стволы стоят), витрификация
   стекла у воды, пар от испарённой жидкости.
5. **Груз**: в центре воронки на обсидиановом постаменте — шалкер **«Секретный груз»**
   (алмазы, изумруды, древние обломки, шанс нетерита, тотемы, ТНТ…).
6. **Радиация**: внутри воронки — случайный набор негативных эффектов (отравление, иссушение,
   тошнота, голод, усталость, слабость, тьма, замедление) + счётчик Гейгера; в зоне выпадений —
   слабые эффекты. Кратер и радиация **остаются навсегда** (это памятник).
7. **Откат**: `/deepevents undo` восстанавливает всё до блока (снапшот в памяти и на диске —
   переживает рестарт) и снимает радиационную зону.

Экономика сбалансирована: нетерит 15%, тотем 30%. Постоянных радиационных зон — максимум 5
(старые вытесняются).

## Ивент 3: Звездопад (мирный)

Ночь (время восстанавливается после ивента), ясно, в небе — **аврора** из 4 цветных лент,
у земли светлячки. Каждые 7–13 секунд падает звезда:

- **Обычная** — 1 осколок, **золотая** (12%) — 2 осколка, **Великая** (2%) — 3 осколка
  и молния (бонус всем поблизости).
- Осколки светятся лучом и исчезают через 90 секунд.
- **3 осколка + Shift+ПКМ** = желание: случайное благословение (удача, регенерация, скорость,
  ночное зрение, звёздный щит, огнестойкость, дыхание, прыжок…).
- **ПКМ осколками по игроку** = общее желание: удача обоим (мирная механика взаимодействия).
- **Общий счётчик желаний** на боссбаре: когда сервер вместе загадает 10 желаний — все онлайн
  получают «благодарность звёзд» (удача II + звёздный щит).
- **Финал**: великая звезда опускается колонной света, тройной салют, удача всем онлайн.
  Осколки «остывают» в аметисты по количеству.

## Быстрая настройка (config.yml)

Ключевые узлы: `general.scheduler` (интервалы, веса), `kraken.*` (HP, аколиты, волны,
щупальца, водовороты, лут), `nuke.*` (радиус/глубина кратера, ударная волна, радиация, лут),
`starfall.*` (длительность, тиры метеоров, желания, благословения). Всё с комментариями.

## Технические гарантии

- 22 JUnit-теста: математика волн (периодичность, амплитуда, контрплей-нырок), равный
  делёж лута, форма кратера (параболоид, вал, гладкий шум), ударная волна.
- `/deepevents selftest` — 10 проверок конфига и математики прямо на сервере.
- Протестировано на реальном Paper 1.21.11 (build 132): чистый сервер и полная сборка
  DeepProgression 3.2.1 (Java 21 и Java 25, с WorldGuard/Towny/CoreProtect).
- Анти-зомби: внутренняя ошибка ивента не оставляет его «висеть» — авто-остановка и откат.
- Анти-дюп/анти-краш: undo-снапшоты в памяти + на диске (GZIP), синхронный откат при
  выключении плагина, отмена генерации кратера при остановке.
